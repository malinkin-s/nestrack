# Nestrack

[English](README.md) · **Русский**

Открытая система учёта выработки для цехов листовой обработки: какие позиции
сменного задания закрыты, кто что сделал и когда — в реальном времени для
мастера и с передачей в ERP.

> **Состояние: планирование.** Архитектура, план и разбивка на задачи
> написаны, кода пока нет. Начать стоит с
> [docs/ARCHITECTURE.ru.md](docs/ARCHITECTURE.ru.md).

---

## Откуда взялся

Nestrack начался с **[finnpower-counter](https://github.com/malinkin-s/finnpower-counter)** —
автономной утилиты, написанной под конкретный станок: координатно-пробивной
Prima Power / Finn-Power, программы для которого готовит постпроцессор
NCeXpress FMS.

Задача, которую она решала, знакома любому цеху, где детали раскладывают на
общие листы. В одном сменном задании много деталей в разном количестве;
чтобы экономить металл, CAM разносит каждую деталь по множеству программ.
Позиция из 20 штук может выходить по 2 и по 4 и закрыться только на 28-й
программе из 30. Оператору нужно знать, что готово полностью, — а при
пересменке это знание жило на стикерах.

finnpower-counter читает управляющие программы и карты наладки, считает,
сколько штук каждой детали даёт смена, и ведёт учёт готовности на одном
рабочем месте. Он остаётся отдельным автономным проектом. Nestrack переносит
ту же идею на весь цех и использует его разбор файлов — проверенный на
реальных сменных заданиях и тысячах реальных карт наладки — как зависимость.

## Что будет уметь

| Кто | Что |
|---|---|
| **Оператор** | Открывает папку задания в клиенте на компьютере, отмечает выполненные программы, видит закрытые позиции; входит по имени и PIN; продолжает работать при обрыве сети |
| **Мастер** | Смотрит выработку в браузере в реальном времени — по операторам, дням, сменам и заданиям; выгружает CSV |
| **Администратор** | Настраивает смены, операторов, рабочие места, срок хранения, Active Directory и подключения к ERP в веб-панели |
| **ERP** | Получает выполненное количество по операциям заказа (Infor SyteLine, 1С, webhook, файлы) или забирает его из API Nestrack |

## Как устроен

```
Клиент оператора (Windows 7+, Python 3.8, один .exe)
        │  HTTPS + Server-Sent Events
        ▼
Сервер (FastAPI · SQLite · Docker или служба Windows)
        ├── веб-страницы мастера и администратора
        ├── Active Directory (LDAPS)
        └── интеграционный модуль → коннекторы к ERP
```

Схемы, решения и их причины — в [docs/ARCHITECTURE.ru.md](docs/ARCHITECTURE.ru.md).

## План

| Этап | Что появляется |
|---|---|
| 0 | Проверка на Windows 7 (условие продолжения), каркас клиента на разборе из finnpower-counter |
| 1 | Сервер: пользователи, роли, рабочие места, настройки, панель администратора, установка в Docker |
| 2 | Клиент подключается: регистрация рабочего места, вход по имени и PIN, вход без связи |
| 3 | Журнал выработки: каждая отметка на сервере, очередь при обрыве связи, изменения сразу видны |
| 4 | Страница мастера, выгрузка в CSV |
| 5 | Сессии: именованные закладки с датой и временем |
| 6 | Эксплуатация: резервные копии, инструкция по установке, срок хранения |
| 7 | Вход через Active Directory, роли по группам |
| 8 | Интеграционный модуль: коннекторы SyteLine, 1С, webhook, файлы; API интеграции |
